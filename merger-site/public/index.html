    ⬇ تحميل
    توثيق API للمطورين (بدون تسجيل دخول — CORS مفتوح)
    MethodEndpointالوظيفة
    POST/api/jobsإنشاء مهمة دمج
    POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤4MB)
    POST/api/jobs/{id}/processتنفيذ الدمج كاملًا → رابط الفيديو
    GET/api/jobs/{id}الحالة + التقدم (0–100) + الرابط
    GET/api/jobs/{id}/videoبث الناتج بدعم Range، و ?download=1
    DELETE/api/jobs/{id}حذف فوري شامل
    GET/api/configالحدود العامة + version
    GET/api/cronحذف المهام المنتهية (يومي)
    curl -X POST /api/jobs -H "Content-Type: application/json" -d '{"videos":["https://example.com/a.mp4","https://example.com/b.mp4"]}'
    curl -X POST /api/jobs/{jobId}/process
# → {"status":"done","videoUrl":"…","downloadUrl":"…","size":…,"duration":…,"resolution":"WxH","expiresAt":"…"}
    curl /api/jobs/{jobId}
curl -H "Range: bytes=0-1023" /api/jobs/{jobId}/video -o part.mp4   # استجابة 206
curl -X DELETE /api/jobs/{jobId}
